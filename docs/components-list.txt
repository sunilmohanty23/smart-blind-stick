================================================================================
                            1. MICROCONTROLLERS
================================================================================

[1] ESP32-WROOM-32 Dev Board
    Quantity: 1
    Purpose: Main communication hub (GPS, GSM, GPRS, SOS, Battery monitoring)
    Specs: Dual-core, 520KB SRAM, 4MB Flash, 3.3V logic
    Wiring:
        - GSM (SIM800L)  → UART1: RX=GPIO26, TX=GPIO27
        - GPS (NEO-6M)   → UART2: RX=GPIO16, TX=GPIO17
        - SOS Button     → GPIO5 (INPUT_PULLUP)
        - Battery 1 ADC  → GPIO34
        - Battery 2 ADC  → GPIO35

[2] Arduino Nano (Clone)
    Quantity: 1
    Purpose: Real-time obstacle detection (Ultrasonic sensors, buzzer)
    Specs: ATmega328P, 2KB SRAM, 32KB Flash, 16MHz, 5V logic
    Wiring:
        - Upper Ultrasonic  → TRIG=D2, ECHO=D3
        - Lower Ultrasonic  → TRIG=D4, ECHO=D5
        - Buzzer           → D6

================================================================================
                              2. SENSORS
================================================================================

[3] Ultrasonic Sensor HC-SR04 (Upper Obstacle)
    Quantity: 1
    Purpose: Detect obstacles at upper body level (head/chest)
    Specs: Range 2-400cm, Accuracy ±3mm, 5V operation
    Alert Logic:
        - 100cm to 50cm  → Slow beep (300ms ON, 300ms OFF)
        - 50cm to 0cm    → Fast beep (100ms ON, 100ms OFF)

[4] Ultrasonic Sensor HC-SR04 (Lower Obstacle / Ground)
    Quantity: 1
    Purpose: Detect ground-level obstacles (curbs, potholes, stairs)
    Specs: Same as above
    Alert Logic:
        - <20cm          → Double pulse beep
        - Pit detection  → Continuous beep (highest priority)

[5] GPS Module NEO-6M (GY-GPS6MV2)
    Quantity: 1
    Purpose: Get real-time location coordinates for SOS and ThingSpeak
    Specs: 50 channels, 1Hz update, Accuracy ±2.5m, 3.3V-5V operation
    Notes: Needs clear sky for fix, 30-60 seconds cold start time

================================================================================
                          3. COMMUNICATION MODULES
================================================================================

[6] GSM Module SIM800L
    Quantity: 1
    Purpose: Send SMS, make calls, send GPRS data to ThingSpeak
    Specs: Quad-band (2G only), 3.4V-4.4V operation, 2A peak current
    Important: 
        - Connect DIRECT to 18650 battery (3.7V-4.2V)
        - Do NOT use boost/buck converter
        - Add 1000uF capacitor across VCC/GND
        - Requires 2G network (VI or Airtel SIM - NOT Jio)
    AT Commands Used:
        - AT              → Check communication
        - AT+CSQ          → Check signal quality
        - AT+CREG?        → Check network registration
        - AT+CMGF=1       → Set SMS text mode
        - AT+CMGS="num"   → Send SMS
        - ATDnumber;      → Make call
        - AT+CIPSTART     → Start GPRS connection
